officecli

A command-line Office suite built for AI agents. officecli reads, creates, and edits Word (.docx), Excel (.xlsx), and PowerPoint (.pptx) files directly — no Microsoft Office, no LibreOffice, no runtime dependencies. Every element in a document is addressed by a 1-based, XPath-like path, so an agent can read, edit, and verify a file the same way it would edit a filesystem.

This is a Rust reimplementation of iOfficeAI/OfficeCLI's core command surface — create / view / get / add / set / remove / batch / validate, the DOM-path addressing system, --prop conventions, and JSON output — so an agent trained on either tool can drive this one with the same muscle memory.

install

Install

Installer scripts detect your platform and drop a single binary on your PATH. Every release ships prebuilt binaries for Linux (x64/arm64), macOS (Apple silicon/Intel), and Windows (x64/ARM64, both built with the MSVC toolchain).

Linux / macOS
curl -fsSL https://github.com/pariharshyamu/office-agent/releases/latest/download/install.sh | sh
Windows (PowerShell)
irm https://github.com/pariharshyamu/office-agent/releases/latest/download/install.ps1 | iex

Binaries install to ~/.local/bin (Windows: %LOCALAPPDATA%\Programs\officecli), and the installer prints PATH instructions if the directory isn't already on it.

Environment variableEffect
OFFICECLI_VERSIONPin a specific release, e.g. OFFICECLI_VERSION=v0.4.0
OFFICECLI_INSTALLInstall to a custom directory instead of the default

Cargo
cargo build --release

quick start

Quick start

Three formats, the same verbs. Create a blank document, then add and set elements by path.

pptx  PowerPoint

Shell
officecli create deck.pptx
officecli add deck.pptx / --type slide --prop title="Q4 Report" --prop background=1A1A2E
officecli add deck.pptx '/slide[1]' --type shape \
    --prop text="Revenue grew 25%" --prop x=2cm --prop y=5cm \
    --prop size=24 --prop color=FFFFFF --prop font=Arial
officecli view deck.pptx outline
# → Slide 1: Q4 Report
# →   Shape 1 [shape] Title 1: Q4 Report
# →   Shape 2 [shape] TextBox 3: Revenue grew 25%

docx  Word

Shell
officecli create report.docx
officecli add report.docx /body --type paragraph --prop text="Summary" --prop style=Heading1
officecli add report.docx /body --type table --prop rows=2 --prop cols=3
officecli set report.docx / --find draft --replace final
officecli set report.docx '/body/p[1]' --find Summary --prop bold=true --prop color=red

xlsx  Excel

Shell
officecli create data.xlsx
officecli set data.xlsx /Sheet1/A1 --prop value=Name --prop bold=true
officecli set data.xlsx /Sheet1/B2 --prop value=91
officecli set data.xlsx /Sheet1/B3 --prop value="=SUM(B2:B2)"
officecli view data.xlsx text
Always quote paths that contain brackets, e.g. '/slide[1]' — an unquoted [1] gets glob-expanded by most shells.
concepts

Path addressing

Every element — a paragraph, a cell, a slide shape — is addressed by a 1-based, XPath-like path. / means the whole document (used for add --type slide, add --type sheet, and whole-document find/replace).

docx/body/p[3]/r[1]
xlsx/Sheet1/A1  ·  $Sheet1:A1  ·  /sheet[2]/B5  ·  /Sheet1/row[5]
pptx/slide[1]/shape[2]  ·  /slide[1]/shape[@name=Title 1]
FormatPath examples
docx/body/p[3], /body/p[3]/r[1], /body/tbl[1]/tr[2]/tc[3]
xlsx/Sheet1/A1, $Sheet1:A1, /sheet[2]/B5, /Sheet1/A1:C10, /Sheet1/row[5]
pptx/slide[1], /slide[1]/shape[2], /slide[1]/shape[@name=Title 1], shape[@id=5]

Friendly aliases work everywhere: paragraph ≡ p, run ≡ r, table ≡ tbl, row ≡ tr, cell ≡ tc.

Indexing is mixed on purpose. Paths are 1-based; --index is 0-based (array convention) — except add --type row on xlsx, where --index is the 1-based row number, matching the OOXML row index and upstream OfficeCLI.
concepts

--prop values

Properties are passed as repeatable --prop key=value flags on add and set. officecli parses common human formats for colors, lengths, dates, and durations so you don't have to pre-convert to EMU or hex.

Colors

FF0000#FF0000redrgb(255,0,0)

Lengths

2cm25mm1in72pt96px914400 (raw EMU)

Font sizes

2424pt

Durations

500ms1.5s

Dates

2026-07-102026-07-10 14:3014:30:00

Booleans

truefalse

Text escapes

\n line break (new paragraph in pptx) · \t tab / list level
concepts

JSON output

Add --json to any command that supports it for a structured envelope agents can parse without scraping text.

Success
{ "ok": true, "data": { "results": [ { "path": "/slide[1]/shape[2]",
  "type": "shape", "text": "Revenue grew 25%",
  "attributes": { "x": "720000", "y": "1800000", "id": "3" } } ] } }
Failure — still goes to stdout, exit code 1
{"ok":false,"error":"..."}
--json is not available on mcp, resident, watch, or help — those don't emit a single report to render. help always prints plain text even if --json is passed.
concepts

Safety flags

Two global flags guard against unwanted writes. They're syntactically accepted on every command, but only take effect on commands that actually save a file: add, set, remove, move, swap, copy, sort, and batch.

FlagEffect
--backupWrite <file>.bak (a copy of the file as it was before this run) before saving.
--dry-runPerform the operation in memory and report the result, but skip the save. Prints (dry run — no changes written) to stderr.
batch --atomicSave only if every operation in the batch succeeded — a failing operation discards the whole batch instead of leaving a partially-applied file.
Shell
officecli set report.docx '/body/p[1]' --prop text=Draft --dry-run
officecli set report.docx '/body/p[1]' --prop text=Final --backup
command reference

Commands

21 built-in commands, grouped by what they do. Anything not on this list is dispatched as a plugin — officecli foo args… runs officecli-foo args… if that executable exists on PATH.

Reading documents

create

Create a blank document. The document type (docx/xlsx/pptx) is inferred from the file extension.

officecli create <file> [--force] [--json]
--force
— overwrite if the file already exists (errors otherwise).
officecli create deck.pptx
view

Inspect a document. mode defaults to outline.

officecli view <file> [mode] [-o FILE] [--json]
mode
— outline · text · stats · html · screenshot · comments · notes (pptx)
-o, --output
— write to a file instead of stdout. Required for screenshot: writes one PNG per page/sheet/slide (out.png, or out-1.png, out-2.png, … when there's more than one).
officecli view deck.pptx screenshot -o deck.png
get

Read one element by path, optionally expanding its children.

officecli get <file> <path> [--depth N] [--computed] [--json]
--depth
— expand children N levels deep (default 0).
--computed
— evaluate xlsx formulas and show the result instead of the raw formula text.
officecli get data.xlsx /Sheet1/C1 --computed
query

Find elements with a CSS-like selector matched against the document tree. See Query language.

officecli query <file> <selector> [--json]
officecli query data.xlsx 'cell[value>5000]'
diff

Content-level comparison of two same-format documents: added / removed / changed nodes with paths and attribute deltas. Built for agent verify loops.

officecli diff <file1> <file2> [--json]
officecli diff before.docx after.docx → /body/p[1] (changed) "Hello there" from=Hello world
dump

Emit replayable batch JSON that recreates the document's content — paragraph/run text and formatting, images with base64 bytes, cell values/formulas/styles, slides, textboxes, transitions.

officecli dump <file> [--json]
officecli dump deck.pptx > ops.json
validate

Check that the OOXML package is structurally sound (parts, relationships, content types).

officecli validate <file> [--json]

Editing documents

add

Add an element under a parent path. Element types and their props are format-specific — see the Word, Excel, and PowerPoint guides.

officecli add <file> <parent> --type T [--prop k=v]… [--index N | --before PATH | --after PATH] [--json]
--type
— element type, e.g. paragraph, shape, sheet, chart.
--prop
— repeatable key=value pair.
--index / --before / --after
— position among siblings (mutually exclusive); default is append.
officecli add deck.pptx / --type slide --prop title="Q4 Report"
set

Modify properties on an element, or run find/replace (path = / for whole-document).

officecli set <file> <path> [--prop k=v]… [--find TEXT [--replace TEXT]] [--json]
--find
— literal text to find; add --prop regex=true to treat it as a regular expression.
--replace
— replacement text (requires --find). Omit it with --prop format flags to format every match instead of replacing text (docx only).
officecli set doc.docx / --find draft --replace final
move

Reposition an element, optionally under a new parent.

officecli move <file> <path> [--to PATH] [--index N | --before PATH | --after PATH] [--json]
--to
— new parent path (defaults to the current parent — a pure reorder).
officecli move deck.pptx '/slide[3]' --before '/slide[1]'
swap

Exchange the positions of two elements of the same kind.

officecli swap <file> <path1> <path2> [--json]
officecli swap deck.pptx '/slide[1]' '/slide[2]'
copy

Duplicate an element — slide, sheet, row, paragraph, table, or shape. Notes, styles, and relationships travel with the copy.

officecli copy <file> <path> [--index N | --before PATH | --after PATH] [--json]
officecli copy data.xlsx /Sheet1 → "Sheet1 (2)"
remove

Delete an element by path. Behavior is format-specific (e.g. an xlsx cell is cleared, a row shifts the rows below it up).

officecli remove <file> <path> [--json]

Spreadsheet-only

calcxlsx

Evaluate a spreadsheet formula against a workbook without writing it to a cell — a quick way to check a computation.

officecli calc <file> <formula> [--json]
officecli calc data.xlsx '=VLOOKUP("West",A2:C99,3,FALSE)'
sortxlsx

Sort a cell range in place by one of its columns. Numeric-aware; refuses ranges containing formulas (rearranging values would silently break them).

officecli sort <file> <range> --by COL [--desc] [--json]
officecli sort data.xlsx 'Sheet1!A2:C99' --by B --desc
exportxlsx

Export a cell range as CSV.

officecli export <file> [--range R] [--sheet S] [-o FILE] [--json]
--range
— e.g. Sheet1!A1:C9; defaults to the sheet's used range.
--sheet
— defaults to the first sheet.
officecli export data.xlsx --range 'Sheet1!A1:C99' -o out.csv

Automation & servers

batch

Run many operations in one save cycle. See Batch operations for the JSON shape.

officecli batch <file> [--commands JSON | --input FILE] [--stop-on-error] [--atomic] [--json]
--commands / --input
— inline JSON or a file (mutually exclusive); without either, reads from stdin on the CLI (not available over MCP, where stdin is the protocol channel).
--stop-on-error
— abort at the first failing operation instead of continuing.
--atomic
— save nothing unless every operation succeeded.
resident

Keep one process alive for agents issuing many commands. Each stdin line is a command string; each response is one compact JSON line. exit or EOF ends the loop.

officecli resident
mcp

Run as a Model Context Protocol server on stdio, exposing a single officecli tool whose one argument is the CLI command string. See MCP server.

officecli mcp
watch

Serve a live-reloading HTML preview of a document on localhost; reloads the browser whenever the file changes on disk.

officecli watch <file> [--port N]
--port
— defaults to 8787; 0 picks a free port.
help

Print the agent-oriented command guide — the same content as this site's reference sections, condensed for a terminal.

officecli help [docx|xlsx|pptx]

word — .docx

Paths & elements

Word documents are a flat sequence of paragraphs and tables under /body, with runs (formatted text spans) nested inside paragraphs and cells.

PathRefers to
/body/p[3]Third paragraph paragraph, para
/body/p[3]/r[1]First run in it run
/body/tbl[1]First table table
/body/tbl[1]/tr[2]/tc[3]Row 2, cell 3 row, cell / td
/comment[1]Comment by id (remove only)

Word content controls (w:sdt) are transparent: paragraphs wrapped inside them address and edit as plain /body/p[N] paths — the wrapper is preserved on save without you ever needing to reference it.

Element types (add --type …)

TypeProps
paragraphtext, style (Normal/Title/Heading1–3), align (left/center/right/justify), bold, italic, underline, size (pt), color, font, highlight. \n in text becomes a line break, \t a tab. Also takes list=bullet|number|none and level=0-8 directly.
runSame text/format props; parent must be a paragraph.
tablerows, cols (default 2×2).
rowParent must be a table; copies the column count.
breakPage break.
imagesrc=file.png (PNG/JPEG/GIF) or srcdata=BASE64, w/h (optional, aspect kept), align.
listitems="One\nTwo\n\tNested" (\n separates items, leading \t = deeper level), kind=bullet|number, plus any paragraph format props.
hyperlinkurl, text; appended to a paragraph.
tocTable of contents field (parent /body); levels (e.g. "1-3"). Inserted as a dirty field with updateFields set — Word populates it on open.
fieldkind=page|numpages|date|time|filename|author, or raw code="..." (parent = a paragraph).
chartkind=column|bar|line|pie|scatter, categories="Q1,Q2" (scatter: xvalues="1,2"), values="10,20", series=Name, values2=/series2=… for more series, title, w/h. Embeds a real, editable data workbook.
commenttext, author; attaches to a paragraph.
footnotetext; adds a superscript reference and the note text.
header / footertext, align, page-numbers=true, plus format props. Added at /; replaces any existing default one.

set behavior

paragraphtext (replaces all runs), style, align, plus run format props applied to every run.
runtext + format props.
cell (tc)text, plus run format props applied inside the cell.

View & remove

view modes: outline (headings + tables), text, stats, html, comments, screenshot. remove /header and remove /footer delete the default header/footer; remove /comment[N] deletes a comment and its body markers.

word — .docx

Page setup

Set on the document root (/).

Shell
officecli set doc.docx / --prop orientation=landscape
officecli set doc.docx / --prop page-size=a4        # letter/a4/a3/legal/WxH
officecli set doc.docx / --prop margins=1in         # or margin-top/-right/-bottom/-left

Page size accepts letter/a4/a3/legal or an explicit WxH (e.g. 8.5inx11in). Margins accept one uniform value or per-side margin-top/-right/-bottom/-left. page-numbers=true on a header/footer inserts live PAGE/NUMPAGES fields.

word — .docx

Find & replace

Shell
officecli set doc.docx / --find draft --replace final          # whole document
officecli set doc.docx '/body/p[1]' --find weather --prop bold=true   # format hits
officecli set doc.docx / --find '\d+%' --prop regex=true --replace "N%"

Matches work across run boundaries. Formatting matched text (--find plus format props, without --replace) splits runs at match boundaries — this mode is docx-only. Matching is case-sensitive; use (?i)… with regex=true for case-insensitive search.

word — .docx

Comments, footnotes, TOC, fields

Shell
officecli add report.docx '/body/p[2]' --type comment --prop text="Check this" --prop author=Reviewer
officecli view report.docx comments
officecli remove report.docx '/comment[1]'
officecli add report.docx '/body/p[2]' --type footnote --prop text="Source: ..."
officecli add report.docx /body --type toc --index 0
officecli add report.docx '/body/p[5]' --type field --prop kind=page
excel — .xlsx

Paths & cells

Cells are created on demand — there's no separate "add cell" step, just set.

PathRefers to
/Sheet1/A1Cell (sheet by name) — also $Sheet1:A1
/sheet[2]/B5Cell (sheet by position)
/Sheet1/A1:C10Range (get only)
/Sheet1/row[5]Row 5
/Sheet1/BColumn B — also /Sheet1/col[2] (remove only)

set props (cells are created on demand)

value=HelloInline string.
value=42Number (auto-detected).
value=2026-07-10Real date cell (auto-detected; type=string opts out).
value="=SUM(A1:A9)"Formula (auto-detected by leading =).
value="{=SUM(A1:A3*B1:B3)}"Legacy array formula (stored as t="array").
type=string|number|boolean|date|formulaForce interpretation.
format=date|datetime|time|percent|currency|integer|0.00|…Number format — friendly name or a raw format code.
url=https://…Hyperlink, styled blue + underline.
comment="note" [author=Name]Cell comment; an empty comment= removes it.
bold, italic, underline, color, size, font, fillCell styling.

Formulas are stored uncalculated — read results with get --computed or calc.

Range, column & row layout

Shell
officecli set data.xlsx '/Sheet1/A1:C1' --prop merge=true    # or merge=false
officecli set data.xlsx /Sheet1/B --prop width=22            # column width (characters)
officecli set data.xlsx '/Sheet1/row[1]' --prop height=28    # row height (points)
excel — .xlsx

Rows, columns & sheets

TypeProps
sheetname (added at /).
rowvalues="a,b,c" and/or c1=…, c2=…. --index N is the 1-based row number; later rows shift down and formula references are rewritten to follow.
columnat=B (or --index N, 1-based), values="a,b,c" (fills down from row 1), r1=…, r2=…. Cells shift right and formula references follow.
csvsrc=file.csv (or data=…), at=A1; values are auto-typed (numbers, dates, strings).

Formula references are rewritten on both row and column inserts/removals, across every sheet in the workbook (Sheet2!B5-style references included).

ActionBehavior
set /Sheet1 --prop name=BudgetRename a sheet.
copy /Sheet1Duplicate a sheet → "Sheet1 (2)".
copy /Sheet1/row[2]Duplicate a row (shifts rows down).
remove /Sheet1Removes the sheet (refused for the last remaining one).
remove /Sheet1/row[5]Removes the row, shifts rows up.
remove /Sheet1/BRemoves column B, shifts columns left; formulas follow.
remove /Sheet1/B2Clears the cell.
export --range 'Sheet1!A1:C9'Cell range as CSV.

Find/replace (set / --find … --replace …) matches string cells only; find+format is not supported for xlsx.

view modes: outline (sheets + ranges), text (grid), stats, html, comments, screenshot (one PNG per sheet, charts drawn in place).

excel — .xlsx

Formula reference

officecli ships a built-in formula evaluator — agents can read computed results with get --computed or calc without ever opening Excel. Cross-sheet references (Sheet2!A1), the full operator set (+ - * / ^ & = <> < > <= >=), and cycle detection (#CIRC!) are all supported.

Shell
officecli set data.xlsx /Sheet1/C1 --prop value="=SUM(B2:B99)"
officecli get data.xlsx /Sheet1/C1 --computed      # → text is the result
officecli calc data.xlsx '=VLOOKUP("West",A2:C99,3,FALSE)'
officecli calc data.xlsx '=AVERAGE(Sheet2!B:B)*1.2'

Array formulas & broadcasting

Ranges used inside a scalar expression broadcast elementwise through operators, so you can write array logic without dragging a formula down a column:

Shell
officecli calc data.xlsx '=SUM(A1:A3*B1:B3)'
officecli calc data.xlsx '=SUM((A1:A3>2)*B1:B3)'
officecli set data.xlsx /Sheet1/C1 --prop value="{=SUM(A1:A3*B1:B3)}"

Mismatched range shapes report #VALUE! rather than silently truncating. Dates respect the workbook's date system (1900 or 1904, via workbookPr date1904).

Errors

Unsupported functions and bad references return Excel-style error values instead of failing the command: #DIV/0!, #REF!, #NAME?, #VALUE!, #N/A, #CIRC! (circular reference).

excel — .xlsx

Charts & pivots

Charts

Shell
# chart over live cells (first column = categories, first row = headers)
officecli add data.xlsx /Sheet1 --type chart \
    --prop data=A1:C9 --prop kind=column --prop title="Sales" --prop at=E2

# scatter: first data column is the x series
officecli add data.xlsx /Sheet1 --type chart --prop kind=scatter --prop data=A1:B9

Kinds: column, bar, line, pie, scatter. xlsx charts reference live cells — they update when the underlying data changes, unlike pptx/docx charts which cache their data. Charts parse cleanly in openpyxl and render with real axes, series colors, and legends in view screenshot.

Pivot summaries

Shell
officecli add data.xlsx / --type pivot --prop source=A1:C99 \
    --prop rows=Region --prop values=Sales --prop agg=sum
officecli add data.xlsx / --type pivot --prop source=A1:C99 \
    --prop rows=Region --prop values=Sales --prop native=true

Writes a computed group-by summary (sum/count/avg/min/max, plus a Grand Total) to a new sheet. With native=true, the same cells additionally get a real PivotTable definition — pivot cache and records with refreshOnLoad — so Excel shows an interactive pivot that rebuilds from the source range on open (one row field and one value field).

excel — .xlsx

Dates, number formats & CSV

Shell
officecli set data.xlsx /Sheet1/A1 --prop value=2026-07-10        # real date cell
officecli set data.xlsx /Sheet1/B1 --prop value=0.185 --prop format=0.00%
officecli set data.xlsx /Sheet1/C1 --prop value=1234.5 --prop format=currency
officecli add data.xlsx /Sheet1 --type csv --prop src=input.csv --prop at=A1
officecli export data.xlsx --range 'Sheet1!A1:C99' -o out.csv

ISO dates/times auto-detect into serial numbers with a date format (openpyxl reads them back as native datetime objects); type=string opts out. format= accepts date/datetime/time/percent/currency/integer/0.00/a raw format code. CSV import auto-types numbers and dates; export quotes RFC 4180-style.

powerpoint — .pptx

Paths & shapes

PathRefers to
/slide[1]First slide
/slide[1]/shape[2]Second shape (positional)
/slide[1]/shape[@name=Title 1]Shape by name
/slide[1]/shape[@id=5]Shape by stable id — preferred in workflows, since ids don't shift when shapes are reordered
shape[1] is usually the title textbox on slides created with --prop title=…; content shapes start at shape[2].

Element types (add --type …)

TypeProps
slidetitle, background (color), notes (added at /; position with --index/--before/--after).
shapeTextbox. text, x, y, w, h (any length unit), size (pt), color, bold, italic, font, align, fill, name, url (hyperlink), list=bullet|number. \n in text starts a new paragraph; leading \t sets the list level.
imagesrc=file.png or srcdata=BASE64, x, y, w, h.
chartkind=column|bar|line|pie|scatter (scatter: xvalues="1,2,4"), categories="Q1,Q2", values="10,20", series=Name, values2=/series2=… for more series, title, x/y/w/h. Data is cached in the chart plus embedded as a real workbook, so PowerPoint's "Edit Data" opens a live sheet.
tabledata="a,b\nc,d" (CSV-shaped), or rows/cols for an empty grid; header=true styles the first row; x/y/w/h. Replace cells later with set --prop data=….

Theme colors (schemeClr accent1..6, bg/tx aliases, lumMod/lumOff) are resolved through theme1.xml in views, screenshots, and dump, so corporate decks keep their palette.

Find/replace (set / --find … --replace …) works across whole-document text spans; find+format is not supported for pptx. view modes: outline (slides + shapes), text, stats, html, notes, screenshot.

Transitions

fade, cut, push, wipe, dissolve, circle, diamond, plus, wedge, wheel, zoom, cover, pull, split, blinds, checker, comb, strips, newsflash, random, none — plus direction=, speed=slow|medium|fast (or a duration), and advance=5s.

Animations

Click-triggered entrance effects built as a standard p:timing tree:

appearInstant visibility toggle.
fadeFade-in filter effect.
wipeDirectional wipe filter.
fly-indirection=left|right|top|bottom — built from ppt_x/ppt_y motion behaviors.
motion-pathpath="0.25,0.1 0.5,0" — waypoints as fractions of the slide size, or a raw "M 0 0 L … E" path string.

Both take duration=500ms and delay=0ms.

query language

Selector syntax

CSS-like selectors matched against the document tree. Predicates test the same attributes get shows (or the node text via value/text).

Shell
officecli query report.docx 'paragraph[style=Normal] > run[font!=Arial]'
officecli query report.docx 'run[bold=true]'
officecli query data.xlsx 'cell[value>5000]'
officecli query deck.pptx ':contains("Revenue")'
SyntaxMeaning
a > bDirect parent/child chain.
[attr=value]Exact match.
[attr!=value]Not equal.
[attr~=value]Substring match.
[attr>=v] [attr<=v] [attr>v] [attr<v]Numeric comparison when both sides are numbers.
:contains("text")Pseudo-class — node text contains the string.
:emptyPseudo-class — node has no text.
automation

MCP server

officecli mcp runs a Model Context Protocol server on stdio, exposing a single officecli tool whose one argument is the CLI command string — the same design as upstream OfficeCLI.

Claude Code
claude mcp add officecli -- /path/to/officecli mcp
Generic MCP config
{ "mcpServers": { "officecli": {
  "command": "/path/to/officecli",
  "args": ["mcp"] } } }
mcp, resident, and watch are foreground servers and cannot be nested — running mcp from inside an MCP session, or batch with no --commands/--input (which would read stdin) over MCP, errors instead of hanging, since stdin is the protocol channel. Plugin dispatch is also unavailable over MCP/resident.
automation

Resident mode

officecli resident keeps one process alive for agents issuing many commands, avoiding per-command process-startup cost.

Shell
officecli resident
> view deck.pptx outline
{"ok":true,"data":{...}}
> set deck.pptx '/slide[1]' --prop background=112233
{"ok":true,"data":{...}}
> exit

Each stdin line is a full command string; each response is one compact JSON line. exit or EOF ends the loop.

automation

Batch operations

Run many operations against one file in a single save cycle — much faster than one process invocation per edit.

Shell
echo '[
  {"command":"set","path":"/Sheet1/A1","props":{"value":"Name","bold":"true"}},
  {"command":"set","path":"/Sheet1/B1","props":{"value":"Score","bold":"true"}}
]' | officecli batch data.xlsx --json

Items support command (or op), path/parent, type, props, index, before, after, find, replace, depth, mode. Continues on error by default (exit code 1 if anything failed); --stop-on-error aborts at the first failure; --atomic discards every change unless the whole batch succeeded.

dump → batch round-trip

dump emits replayable batch JSON that batch can apply to a fresh file — useful for cloning a document's content into a new template, or for regression-testing that a round-trip is lossless.

Shell
officecli dump deck.pptx > ops.json
officecli create copy.pptx
officecli batch copy.pptx --input ops.json
automation

Plugins

Any subcommand that isn't one of the 21 built-ins dispatches to an external plugin.

Shell
officecli redact report.docx --pattern SSN
# → runs `officecli-redact report.docx --pattern SSN` if it exists on PATH

The plugin receives every argument after its own name and its exit code is passed straight through. Not available from inside mcp or resident — both run with a restricted execution context since a nested process could interfere with the protocol channel.

reference

What's implemented per format

Every mutating command supports --backup, --dry-run, and (for batch) --atomic. diff compares two documents content-wise for verify loops. Blank documents created by create open without repair prompts in Word, Excel, PowerPoint, and LibreOffice, and parse with python-docx, openpyxl, and python-pptx — used as reference validators in CI.

docx Word

Paragraphs (text, style Normal/Title/Heading1–3, align), runs (bold/italic/underline/size/color/font/highlight), bulleted/numbered lists with nesting, hyperlinks, tables (create, add row, set cell text + formatting), page breaks, images, inline charts (column/bar/line/pie/scatter with an embedded editable workbook), comments (add/list/remove), footnotes, TOC and fields, headers/footers with page numbers, page setup (orientation/size/margins), copy, transparent w:sdt content controls, insert before/after/at index, whole-scope find/replace and find+format with run splitting, outline/text/stats/html/comments/screenshot views.

xlsx Excel

Cells created on demand via set (strings, numbers, booleans, real dates/times in both the 1900 and 1904 date systems, formulas auto-detected by =, array formulas via {=SUM(A1:A3*B1:B3)}), a built-in formula evaluator (~45 functions incl. SUMPRODUCT/TEXTJOIN, elementwise array broadcasting), number formats (percent/currency/custom codes), hyperlinks, cell comments (with the VML note shapes Excel needs to display them), CSV import/export, sort, merged cells, column widths and row heights, shared-string-aware reads, cell styling through a styles-table manager, sheets (add/rename/remove/copy), rows and columns (insert/remove/copy with shifts and workbook-wide formula-reference rewriting), charts over live ranges, computed pivot summaries (+ opt-in native PivotTables), ranges on get, $Sheet:A1 addressing, find/replace over string cells, grid/outline/stats/html/comments/screenshot views. Formulas are stored uncalculated with fullCalcOnLoad so Excel/LibreOffice recalculate on open.

pptx PowerPoint

Slides (add with title/background/notes, position with --index/--before/--after, copy with notes, remove with full relationship cleanup), textbox shapes (text, x/y/w/h in any length unit, size/color/bold/italic/font/align/fill/name/url, bullet/numbered lists with levels), tables (CSV-shaped data, styled header, editable cells), speaker notes, images, charts (column/bar/line/pie/scatter, each with an embedded workbook so PowerPoint's "Edit Data" opens a live sheet), slide transitions, entrance animations incl. directional fly-in and custom motion paths, theme-color resolution (schemeClr + HSL-based lumMod/lumOff), shape addressing by position, @name=, or @id=, slide background, find/replace across slides, outline/text/stats/html/notes/screenshot views.

reference

Known limitations

This is a focused port, not a feature-complete clone. Honest edges of the implemented features:

Screenshot rendering
view screenshot is an approximation — PNG/JPEG/GIF images composite, charts draw from their cached data, justified text stretches its word gaps, and italics are synthetic obliques — but it is not a print-accurate Office renderer.
Formula coverage
The evaluator covers ~45 common functions plus elementwise array broadcasting, not the full Excel function library.
Native PivotTables
--prop native=true supports one row field and one data field over the computed summary — complex layouts (column fields, filters, multiple values) remain computed-only.
Cell comments
xlsx cell comments are classic notes (with VML shapes), not threaded comments.
Theme color transforms
lumMod/lumOff use HSL luminance like Office, within a rounding hair of PowerPoint's palette; tint/shade remain linear blends.
Round-tripping
dump is a high-fidelity content replay, not a byte-identical round-trip.

The architecture — a lossless XML DOM over the zip package, one handler per format behind a common trait — is designed so the remaining gaps can be closed incrementally.

Source layout

Only the parts of a document you actually touch are rewritten — the DOM preserves qualified names, attribute order, and text verbatim, so editing one paragraph never reshuffles the rest of the file.
